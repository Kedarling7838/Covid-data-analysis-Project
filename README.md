COVID Disease Data Analysis

A comprehensive Exploratory Data Analysis (EDA) project focused on COVID-19 disease-related data. This project uses Python data analysis and visualization libraries to explore patient demographics, infection patterns, hospitalization trends, vaccination impact, reinfection rates, and recovery outcomes.

Project Overview

The objective of this project is to analyze a COVID-19 disease dataset and extract meaningful insights related to:

Patient demographics
COVID-19 strains
Symptoms and severity
Hospitalization and ICU admissions
Vaccination status and doses received
Reinfection patterns
Recovery rates
Long COVID symptoms
Lifestyle factors such as smoking status
Regional trends and distributions

The project follows a complete data analysis workflow including data loading, understanding, cleaning, exploration, and visualization.

Installation

Clone the repository:

git clone https://github.com/your-username/COVID-Disease-Data-Analysis.git

Navigate to the project directory:

cd COVID-Disease-Data-Analysis

Install dependencies:

pip install pandas numpy matplotlib seaborn jupyter

Launch Jupyter Notebook:

jupyter notebook
